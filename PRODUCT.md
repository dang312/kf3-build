# Product

## Register

product

## Users

Killing Floor 3 players use KF3 Build while planning, comparing, and sharing a perk setup. Their primary task is choosing one skill in each unlocked tier quickly, while still being able to inspect the uncertain source data behind an effect.

## Product Purpose

KF3 Build simulates a perk skill tree: select a Perk and Level, choose skills across Passives, Throwable, and Gadget trees, and review the resulting Build Summary. It gives players a fast, trustworthy planning surface before loadouts, gun mods, and share links are added.

## Brand Personality

Rugged, tactical, decisive. The tool should feel like a legible in-game armory terminal, not a generic dashboard or a literal game UI clone.

## Anti-references

Avoid bright sci-fi neon, decorative glassmorphism, oversized soft card grids, and generic SaaS dashboards. Do not obscure provisional game data with official-looking certainty.

## Design Principles

1. Make tier-by-tier comparison immediate.
2. Make selected, available, and locked states unmistakable.
3. Put the active Build Summary within reach without competing with the tree.
4. Use game-inspired texture and hardware-like framing sparingly to support, not obstruct, task flow.
5. Be candid when source data or derived values need verification.

## Accessibility & Inclusion

Meet WCAG AA contrast, preserve semantic controls and keyboard focus, communicate selection and lock state without color alone, and respect reduced-motion preferences. The skill tree and Build Summary must remain usable on mobile screens.
