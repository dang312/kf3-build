# kf3-build

A Killing Floor 3 website for character builds and loadouts.

## Current target

The first target is an in-game skill-tree simulator:

- Choose a character/perk and level.
- Show every skill tier by category (`passives`, `throwable`, `gadget`).
- Display each skill's name, unlock level, icon if available, and effect details.
- Let users select skills using rules that match the game.
- Summarize the build outcome after skills are selected.

Future agents should read [`AGENTS.md`](./AGENTS.md) before working in this repo.

## Essential
