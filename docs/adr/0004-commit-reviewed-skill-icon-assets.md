# Commit reviewed skill icon assets

Reviewed, optimized KF3 skill icon images may be committed to the webapp because the project is a build simulator that supports the game and needs icon-first skill nodes to follow the in-game skill tree UI. Raw game archives, raw texture exports, bulk icon dumps, and unreviewed assets remain out of git; every promoted icon should have source provenance so patch updates can be audited.
